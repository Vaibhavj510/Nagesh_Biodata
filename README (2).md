## Files

| File | Purpose |
|---|---|
| `index.html` | Main portfolio page |
| `photo.jpg` | Hero profile photo |
| `biodata.pdf` | Downloadable biodata |

## How to Update

**Add or change photo**
Rename your photo to `photo.jpg` and replace the existing file.
In `index.html`, uncomment the `<img>` tag in the Hero section and remove the placeholder div.

**Update contact links**
Search for `wa.me` to update the WhatsApp number.
Search for `mailto:` to update the email address.
Replace `#` in Instagram and LinkedIn buttons with actual profile URLs when ready.

**Biodata download**
Replace `biodata.pdf` with the updated file. Keep the same filename.

## Deploy Changes

1. Edit the file
2. Go to your GitHub repo
3. Click the file → Edit (pencil icon) or drag and drop the new file
4. Commit changes — the site updates automatically within a minute
